# Los Idos Arcade

**Los Idos Arcade** es una aplicación web de juegos desarrollada con Python, HTML, CSS y JavaScript.  
El proyecto permite registrar usuarios, iniciar sesión, jugar distintos minijuegos y guardar los resultados en una base de datos.

La idea principal del proyecto es reunir varios juegos simples dentro de una misma plataforma web, con una interfaz visual, sistema de usuarios, dashboard de puntajes y persistencia de datos.

---

## Tecnologías utilizadas

- **Python** para el backend y la lógica principal del servidor.
- **HTML, CSS y JavaScript** para el frontend.
- **MongoDB Atlas** como base de datos en la nube.
- **PyMongo** para conectar Python con MongoDB.
- **python-dotenv** para manejar variables de entorno en desarrollo local.
- **Vercel** para el despliegue online del proyecto.
- **GitHub** para el control de versiones y trabajo colaborativo.

---

## Funcionalidades principales

- Registro de usuarios.
- Inicio y cierre de sesión.
- Dashboard con últimas partidas y puntajes.
- Menú principal con juegos disponibles.
- Persistencia de usuarios, partidas y resultados.
- Conexión a MongoDB.
- Despliegue del proyecto en Vercel.

---

## Juegos incluidos

El proyecto incluye los siguientes juegos:

- **Ahorcado**
- **Auto con obstáculos**
- **Torres de Hanoi**
- **Memoria**
- **Penales**
- **Piedra, Papel o Tijera**

Cada juego funciona como un módulo independiente dentro de la plataforma, pero todos comparten el mismo sistema de login, sesiones y guardado de puntajes.
